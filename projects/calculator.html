Java Project: Simple Calculator

This project is a beginner-friendly Java calculator designed to help new programmers understand variables, operators, decision-making, and input/output in Java.

The calculator performs basic operations such as:

  • Addition (+)
  • Subtraction (-)
  • Multiplication (×)
  • Division (÷)

This project supports visual and Deaf/hard-of-hearing learners through sign-supported explanations available on the platform.

Learning Objectives

  • Understanding Java data types
  • Declaring and using variables
  • Applying arithmetic operators
  • Using conditional statements
  • Designing simple user input logic

How the Program Works

The user enters two numbers, chooses an arithmetic operator, and the program calculates and prints the result. The calculator includes safety checks for invalid operators and division by zero.
